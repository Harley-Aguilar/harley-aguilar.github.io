Privacidade e segurança

Atualizado em 1º de novembro de 2026

Este portfólio usa HTTPS para criptografar os dados em trânsito. Nenhum site pode garantir segurança absoluta.

Navegação no portfólio

O site não possui formulário de contato, scripts de analytics ou rastreadores publicitários. Não solicita o envio de dados pessoais. O GitHub Pages hospeda o site e pode processar dados técnicos das requisições, incluindo endereços IP, conforme sua própria política de privacidade.

Vídeos e links externos

Os players do YouTube só são carregados quando você escolhe reproduzir um vídeo, usando youtube-nocookie.com. A reprodução conecta você ao YouTube e pode envolver dados técnicos, cookies ou armazenamento local conforme as políticas do Google. Links de e-mail e redes sociais abrem serviços com práticas próprias de privacidade.

Suas preferências

Apenas a confirmação de leitura do aviso é salva no armazenamento local deste navegador. Ela não é enviada a mim. Limpe os dados do site para exibir o aviso novamente. Se o armazenamento estiver indisponível, o aviso poderá reaparecer.

Contato

Se você enviar um e-mail, seu provedor processará a mensagem. Para questões de privacidade, use contatoharleya@gmail.com.
